# Giant Biome Trees (`giant_biome_trees`)

Este mod añade estructuras de árboles colosales procedurales únicos a cada bioma del juego base (`default`) en **Luanti (Minetest)**.

## Instalación

1. Descarga o clona esta carpeta con el nombre `giant_biome_trees`.
2. Mueve la carpeta a tu directorio de mods:
   - **Linux**: `~/.minetest/mods/`
   - **Windows**: `C:\Users\<Usuario>\AppData\Roaming\luanti\mods\` o en la subcarpeta `mods/` de la instalación portable.
   - **macOS**: `~/Library/Application Support/luanti/mods/`
3. Activa el mod en la configuración de tu mundo desde el menú principal de Luanti.
4. Genera un nuevo mundo para ver la aparición procedural en la fase Mapgen.
